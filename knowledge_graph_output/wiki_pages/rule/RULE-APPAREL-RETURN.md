# 服饰鞋帽眼镜类商品退换货细则

> **实体 ID**：`RULE-APPAREL-RETURN` ｜ **类型**：`rule` ｜ **层级**：`general`

## 当前结论

服饰鞋帽眼镜类商品退换货细则：服饰类自收到商品之日起7天内可退货、15天可换货。出于安全卫生考虑，内衣裤、袜子、泳衣、定制眼镜不予退换（质量问题除外）；吊牌、包装及附件标签破损或丢失不予退换。个人原因损坏（修改尺寸、洗涤等）不予退货。
