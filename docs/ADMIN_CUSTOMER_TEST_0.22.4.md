# 后台顾客对话测试 0.22.4

本机开发环境在设置 `CUSTOMER_TEST_ENABLED=true` 后，打开 `/admin`，进入“智能客服”页即可直接以顾客身份测试客服 Agent。

对话测试卡片不再需要客户端 ID、主体标识或客户端密钥。可点击“保修咨询”“发货时效”“转人工”填入案例，也可直接输入问题；“新会话”会生成隔离的新测试会话。

发送后，页面会显示实际客服回答、意图、风险和原因、人工接管状态、会话/追踪号和引用来源；同时自动切换到“虚拟验收”范围，便于回放该测试会话。预置上下文为晴川旗舰店 `qingchuan-flagship-001` 和商品 `QC-AF5-WHITE`。

该入口只调用回环受限的 `/v1/test/customer-chat`，所有会话标为 `simulation/local-customer-test`，不会进入默认运营数据，也不会写入外部渠道。生产客户接口 `/v1/chat` 的客户端认证保持不变；生产环境应保持 `CUSTOMER_TEST_ENABLED=false`。
