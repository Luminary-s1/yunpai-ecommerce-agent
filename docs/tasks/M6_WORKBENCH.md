## 模块信息与确认

**阶段**：`3 业务应用`　**排程方式**：`并行`

### 模块背景

```
开发竞品分析子系统：竞品数据的录入与结构化管理，以及利用模型生成竞品对比
分析报告。这是四个业务模块中相对独立的一个。

本模块的核心约束是"竞品事实必须可追溯、可解释、经人工确认"：上游 SKU 对应
关系可能把不同容量、套装或型号误判为同款，价格和口碑若直接进入模型会形成
不可追溯的错误建议。因此竞品数据先经过可解释的同款候选评分与人工裁决，
批准后其价格、卖点与脱敏聚合口碑才允许进入分析与 Agent 建议。

本模块登记为项目业务模块注册表中的 competitive，复用项目统一的租户隔离、
来源版本与载荷哈希、幂等写入、乐观锁、审计和管理后台底座。
不保存评论者身份或原始评论内容，不自动改价。
```

### 总体需求

```
1. 竞品数据结构化管理
   定义竞品数据 Schema，包含标准维度（商品名称、价格、核心卖点、用户评价摘要、
   评分、销量排名）并支持自定义分析维度扩展。提供完整 CRUD、手动表单录入和
   CSV 批量导入（含字段格式校验、数据去重、异常行报错），支持按品类、品牌、
   价格区间、评分范围等多维组合筛选查询，竞品数据可关联自有商品作为对比基准。

2. 竞品对比分析引擎
   输入自有商品数据与竞品数据列表，执行多维度对比：价格区间对比（纯数据计算）、
   核心卖点差异分析（模型推理）、用户评价情感倾向对比（模型推断或规则匹配）、
   市场定位建议（模型推理）。使用竞品分析 Prompt 模板组装上下文，
   支持用户自定义选择分析维度。

3. 报告呈现与导出
   报告结构化呈现——先对比表格（价格、评分、卖点一目了然），再文字解读
   （差异分析 + 建议），支持导出为文本或 Markdown 格式。

约束：可量化维度必须有数值计算支撑，不能是空泛表述；
分析只输出建议，不执行改价、下架或投放动作；
未经人工批准的同款匹配不得进入分析结论。
```

### 验收标准

```
【功能验收】
1. 能通过 API 或 CSV 录入竞品商品数据并持久化存储
2. 支持按品类、品牌、价格区间、评分范围筛选查询
3. CSV 批量导入含格式校验和去重，异常行有明确的字段级报错且不导致整批失败
4. 自定义维度可扩展并参与查询
5. 竞品数据可关联自有商品，设定对比基准
6. 输入自有商品与至少 3 个竞品数据后，能生成包含价格对比、卖点差异分析、
   评价倾向对比和市场定位建议的结构化分析报告
7. 报告内容有数据支撑且逻辑清晰，价格等可量化维度有数值计算
8. 支持维度勾选（如只看价格和评价，不看卖点）
9. 报告导出为文本或 Markdown 功能可用

【工程验收】
10. 全量测试通过且用例数增长可归因
11. 每项能力具备反证：临时移除后对应测试必须失败
12. 重复导入按来源版本与载荷哈希幂等，旧版本拒绝、同版本冲突可识别
13. 跨租户数据隔离
14. 未批准的同款匹配不进入分析结论，具备可验证的门禁

【边界声明】
不保存评论者身份或原始评论内容，只保存脱敏聚合口碑；
不自动改价、不自动调整投放；
竞品数据来源必须为授权 API、许可供应商、人工录入或显式虚拟样本。
```

   + 模型推理调用 + 报告格式化 + 导出功能

【文档交付】

### 工作包 4：竞品对比分析引擎开发

**任务名称**

```
竞品对比分析引擎开发
```

**任务内容**

```
利用模型对自有商品与竞品进行多维度对比分析。输入：自有商品数据 + 竞品数据
列表。输出分析报告包含：价格区间对比、核心卖点差异分析、用户评价情感倾向对比、
市场定位建议。使用竞品分析 Prompt 模板，支持自定义分析维度选择。

具体工作：
1. 价格区间对比：输出价格差异百分比和区间分布（纯数据计算）
2. 核心卖点差异分析：提取各自卖点并生成差异化解读（模型推理）
3. 用户评价情感倾向对比：输出正面 / 负面 / 中性倾向占比
4. 市场定位建议：基于以上对比生成可执行的定位建议
5. 自定义分析维度选择能力
6. 报告结构化呈现与导出
```

**具体需求**

```
分析报告需结构化呈现（表格 + 文字解读）；
评价情感分析可使用模型推断或规则匹配的混合方案，保证本阶段可用；
报告需支持导出；
可量化维度必须有数值计算支撑，不能是空泛表述；
分析输入只允许使用经人工批准的同款匹配数据；
不保存评论者身份或原始评论内容；
分析只输出建议，不执行改价或投放动作。
```

**验收标准**

```
1. 输入竞品数据后能生成结构化的对比分析报告，分析内容有数据支撑且逻辑清晰
2. 价格对比有明确的数值计算结果
3. 情感倾向占比输出可用且与人工判读基本一致
4. 市场定位建议引用了具体对比结论
5. 维度选择生效，未勾选的维度不出现在报告中
6. 反证：移除批准门禁后未批准数据必须能被检出进入了分析
```

**交接内容**

```
竞品分析引擎服务 + 分析 API + 情感分析逻辑 + 维度选择能力
```
