## 模块信息与确认

**阶段**：`3 业务应用`　**排程方式**：`并行`

### 模块背景

```
开发运营辅助后端：运营数据解析接口、营销文案生成引擎、运营分析报告生成。
将电商运营数据通过模型转化为可读的文案和分析洞察。

本模块的定位是"代码负责事实，模型负责表达"——销售、投放、转化率、客单价和
ROI 等所有数值由代码计算，模型只负责文字解读与文案撰写，不能修改统计值。
所有生成的文案在人工审核前不可发布。

本模块登记为项目业务模块注册表中的 ops_assistant，与商品、订单、仓储、竞品、
营销、财务、指标等模块并列，复用项目统一的租户隔离、来源版本、幂等写入、
审计与管理后台底座。
```

### 总体需求

```
1. 运营数据接口
   支持 CSV / JSON 文件上传和表单手动录入两种方式，解析商品销量、访客数、
   转化率、客单价等核心运营指标，执行格式校验和数值合法性检查，
   结构化持久化并提供查询 API 供下游报告模块消费。
   需兼容常见电商平台（淘宝 / 京东 / 抖音商家后台）的导出模板。

2. 营销文案生成
   输入商品信息（名称、卖点、目标人群）→ 选择文案风格 → 组装 Prompt 模板 →
   调用模型生成 → 返回多版本文案供选择。支持单次和批量生成，
   每种风格有独立 Prompt 变体，文案长度可控，生成结果支持编辑后重新生成。

3. 运营分析报告
   消费结构化运营数据，计算销售趋势环比与同比、流量转化漏斗、客单价变化，
   基于可配置阈值检测异常指标并触发预警，调用模型生成文字版运营洞察和
   优化建议，输出结构化报告并支持导出。

约束：所有统计值由代码计算，模型不得修改；模型不可用时逐条降级为确定性模板
并显式标记生成方式；报告仅给出数据解读与建议，不执行预算、价格、库存或
发布操作。
```

### 验收标准

```
【功能验收】
1. 上传符合格式的 CSV / JSON 文件后能正确解析并返回结构化数据
2. 上传格式异常的文件时返回明确的错误定位信息（哪一行、哪个字段出错）
3. 表单手动录入功能可用且数据正确入库
4. 数据查询 API 返回正确的历史运营数据，支持按日期范围与商品维度查询
5. 至少通过 3 种不同电商平台导出格式的解析验证
6. 输入商品信息后能生成多种风格的营销文案，内容质量和多样性经验证可用
7. 文案长度可控，支持编辑后重新生成
8. 输入一周以上的运营数据后能生成包含数据概览、趋势分析、异常预警、
   优化建议的完整报告
9. 趋势分析中的环比与同比数值计算正确（人工核对）
10. 异常预警能正确触发（输入异常数据时能识别并标注）
11. 优化建议引用了具体数据指标而非空泛表述
12. 报告导出为文本文件功能可用

【工程验收】
13. 全量测试通过且用例数增长可归因
14. 每项能力具备反证：临时移除后对应测试必须失败
15. 数据写入按租户、数据集、日期、渠道幂等，重复导入不产生重复记录
16. 跨租户数据隔离，其他租户无数据可读
17. 模型调用失败时逐条降级且返回值显式标记生成方式，混合结果不被误标为
    纯模型生成
18. 报告读取不受列表接口展示上限影响，大数据集不被静默截断

【边界声明】
所有候选文案默认不可发布，发布前必须人工审核卖点、价格和促销主张；
虚拟验收数据集与真实运营数据集分离，不混算；
开发数据库与截图仅用于本地验收，不构成生产经营结论。
```

```
   + 平台格式解析适配器

3. 运营分析报告生成服务：报告生成 API + 报告导出 API + 趋势计算逻辑

【配置与结构交付】
```

### 工作包 2：运营数据接口与解析模块开发

**任务名称**

```
运营数据接口与解析模块开发
```

**任务内容**

```
设计运营数据输入接口，支持 CSV / JSON 文件上传或表单手动录入。解析商品销量、
访客数、转化率、客单价等关键运营指标，校验数据格式和合法性，结构化输出供

```

```
单次导入需有行数上限保护，超限明确拒绝而非静默截断；
异常行标记并跳过，不能整批失败。
```

**验收标准**

```

2. 异常格式有明确报错提示，定位到行与字段
```

### 工作包 5：运营分析与报告生成开发

**任务名称**

```
运营分析与报告生成开发
```

**任务内容**

```
开发运营分析报告生成服务：消费结构化运营数据，计算关键分析指标（销售趋势
环比与同比、流量转化漏斗、客单价变化），检测异常指标（基于阈值规则，
如转化率骤降超 30% 触发预警），将数据摘要与分析指令组装后调用模型生成文字版
运营洞察和优化建议，最终输出结构化运营报告（数据概览 → 趋势分析 → 异常预警
→ 优化建议），支持报告导出为文本格式。

具体工作：
1. 实现环比计算（本周 vs 上周）与同比计算（本月 vs 上月）
2. 异常检测阈值抽取到配置文件，支持调整
3. 报告结构补齐独立的异常预警章节
4. 优化建议强制绑定具体数值指标
5. 实现报告导出为文本格式
```

**具体需求**

```
报告需遵循固定结构模板（摘要 → 核心指标 → 趋势分析 → 异常预警 → 优化建议）；
趋势分析需计算环比（本周 vs 上周）和同比（本月 vs 上月）变化率；
异常预警基于可配置的阈值规则（如转化率下降超 30%、销量环比下降超 50%），
阈值需写入配置文件可调整；
优化建议必须引用具体数据（如"本周转化率为 2.3%，较上周下降 35%，建议检查
商品详情页主图是否更换"），不能是空泛的通用建议；
所有统计值由代码计算，模型只负责文字解读；
报告导出需支持纯文本格式，本阶段不要求 PDF；
报告读取不得复用列表接口的展示上限。
```

**验收标准**

```
1. 输入一周以上的运营数据后能生成包含数据概览、趋势分析、异常预警、
   优化建议的完整报告
2. 趋势分析中的环比与同比数值计算正确（人工核对）
3. 异常预警能正确触发（输入异常数据时能识别并标注）
4. 优化建议引用了具体数据指标而非空泛表述
5. 报告导出为文本文件功能可用
6. 501 行以上数据集的报告合计正确，不被列表上限静默截断
7. 反证：调整阈值配置后预警触发行为必须相应变化
```

**交接内容**

```
运营分析报告生成服务（报告生成 API + 报告导出 API + 趋势计算逻辑
+ 异常检测规则配置 + Prompt 组装逻辑）
```
