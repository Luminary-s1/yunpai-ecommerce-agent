## 7. 测试中发现并修复的问题

1. 售后类型使用了口语值 `replacement/return`，领域模型正确拒绝；数据改为受控枚举 `exchange/return_refund`。
2. 竞品同款样本缺少 GTIN，评分未达到可批准阈值；补充一致 GTIN 和正确比较字段后通过质量门，没有绕过审批规则。
3. 库存样本未触发滞销规则；将无销量库存显式设为平均日销 0 后得到 `slow_moving`。
4. 不同配置下客服可能确定性返回知识答案，也可能因模型不可用安全转人工；场景改为同时验证两种允许结果都必须携带来源和上下文快照。
5. 后台侧栏仍显示旧版本号；修正为 0.22.0 并在浏览器复验。
6. 商品保修问题的本地确定性意图词表缺少“保修/质保/维修”，导致正确答案被标成 `general`；补充词表并新增回归后稳定为 `product`。
7. 客服评测最初只适配本地确定性模型，默认关闭模型时把安全转人工误报失败；D13 改为验证两种配置共同必须满足的来源、上下文和禁答边界，D07 继续独立验证正确知识答案或安全转人工分支。
