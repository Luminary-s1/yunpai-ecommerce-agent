# 云湃电商一体机 Agent 0.8.0 测试报告

## 1. 结论

- 测试对象：`yunpai-ecommerce-agent 0.8.0`，SQLite schema v8。
- 本地候选结论：通过。商品、订单/物流/售后、库存、竞品、受控指标、Agent 工具执行器和管理后台在虚拟数据范围内满足本报告验收项。
- 自动化结果：67 项测试全部通过，无失败、无跳过、无警告。
- 离线安全评测：20/20 通过。
- 覆盖率：全项目语句/分支综合 83%；本轮核心模块 83% 至 94%。
- 生产放行结论：未通过。真实淘宝/ERP 权限、真实模型、客户数据字典、性能与长稳、备份恢复、设备加密、知识/SOP/质检完整管理仍缺少生产证据。

本报告的“通过”只代表本地单机、虚拟/人工数据和模拟外部服务范围，不代表真实平台已联通，也不代表可以跳过上线 Gate。

## 3. 变更范围

本轮新增或加固以下能力：

1. 商品事实：SPU/SKU、渠道商品、售价、状态、属性、来源 ID、来源时间、载荷哈希、版本和质量标识。
2. 订单聚合：订单主表、订单行、脱敏买家引用、物流快照、售后单、不可变版本历史和原子更新。
3. 统一来源版本契约：旧版本拒绝、同版本同载荷幂等、同版本不同载荷冲突、新版本递增。
4. 经营指标：6 项固定指标，只接受严格 QuerySpec，返回定义版本、数据水位、质量和证据数量。
5. Agent 工具：新增商品、订单和经营指标工具；订单工具绑定可信订单号与可信店铺号。
6. 工具执行器：实际超时、只读异常重试、写超时不确定态、验证失败不确定态。
7. 虚拟连接器：商品、订单、库存和竞品 4 类资源可分页拉取并安全重复回放。
8. 管理后台：新增商品库存、订单物流售后、指标卡片、筛选和虚拟同步操作。
9. 数据库：v7 新增经营事实表，v8 为竞品观察补充不可变载荷哈希。

## 10. 未通过的生产 Gate

以下项目没有证据，因此生产放行仍为阻塞：

1. 真实淘宝客服机器人资格、AppKey/AppSecret、奇门场景、request token、tenant ID 和测试店铺。
2. 首个客户 ERP/OMS/WMS 的数据字典、字段映射、增量游标、对账口径和真实重放样本。
3. 真实 GLM 调用的延迟、限流、错误率、输出漂移、成本和降级演练。
4. 多进程/多节点写入、24 小时长稳、峰值并发、磁盘满、断电恢复和 WAL 损坏演练。
5. 加密备份、恢复时间目标、密钥轮换、设备磁盘加密和运维告警闭环。
6. 知识/SOP/质检完整管理、客服暂停/恢复、修改发送、diff 和队列路由。
7. 营销、利润、对账模块及客户确认的成本/毛利口径。
8. API.py 和 operations_api.py 的剩余错误分支覆盖率仍偏低。

## 11. 放行建议

- 可用于：本地演示、接口联调、模块开发、虚拟数据验收、客户数据字典讨论和小规模受控试运行准备。
- 不可用于：未审批的真实平台接管、自动退款/赔付/改价、无人工兜底的客户生产流量。
- 下一 Gate：补齐知识/SOP/质检与客服操作闭环，提高 API 错误路径覆盖；取得真实平台/ERP 凭证后，在隔离测试店铺执行真实数据、消息、人工接管、重放和回滚验收。
